Where this sits in the project

Tom's response to the V1 report changed the model's variable ontology rather than defending the original formulation. Three of his points define V2's structure:

  • Italy is not the victim. BTP–Bund is a thermometer for when the ECB is intervening in the Bund market, not a measure of who is breaking.
  • France is the suspected weak link on the continent, with the UK/London a separate channel.
  • The thresholds are the real question. "Why is the ECB so scared of a drop of the EUR/GBP below 0.85 and a EUR/JPY below 180?"

That decomposes the model into three observable roles — carry condition (Germany–Japan geometry, EUR/JPY, CHF funding), weak-link stress (France first, UK separately), and policy response (BTP–Bund spikes) — which is what V2 implements. This run is the first clean test of that structure.

Threshold convention — resolved

Tom's phrasing settles a question the code had left ambiguous: the feared state is a drop below 180 and 0.85, not a break above. The code already encoded below as the trigger, so no logic changed. The state labels are now explicit (both_below, eurjpy_below_only, both_above) and the convention is written into run_metadata.json so nothing downstream inverts it by accident.

Reproducing this run

Both paths are verified working from a cold start. The offline path needs no network and no key:

cd Luongo_Model_V2_Package
python luongo_model_test_v2.py --offline-snapshots --output outputs/smoke
# → cftc_rows: 1, mof_rows: 1109, tic_rows: 7007, tic_latest_date: 2026-05-01

The live run pulls 27 FRED series plus CFTC, MOF and TIC, and takes roughly four minutes:

export FRED_API_KEY='YOUR_KEY'
python luongo_model_test_v2.py \
  --start 2006-01-01 \
  --events events_v2_template.csv \
  --output outputs/v2_public

Transient FRED read timeouts occur and are retried automatically; one occurred in this run and recovered. All 27 series loaded. Outputs: daily and monthly panels, event study, threshold crossings and crossing event study, regime summary, falsification scorecard, regression report, run metadata, and nine charts.

The one that mattered

Defect 2 took two passes to fix, and the first attempt is instructive. The visible symptom was .fillna(0) in the regime summary. Patching that changed nothing — the counts still summed to 7,530, exactly the number of calendar days in the sample. The actual cause was upstream:

panel["eurjpy_below_180"] = (panel["jpy_per_eur"] < 180.0).astype(float)

A bare < comparison evaluates NaN to False, and .astype(float) freezes that as a hard 0.0. The missingness was destroyed at construction, so no amount of downstream fillna handling could recover it. The fix preserves it with .where(panel["jpy_per_eur"].notna()).

Read this before quoting the table

The table appears to say something dramatic: in the feared both_below state, BTP–Bund is nearly double its calm-state level (137bp against 76bp) while French OAT–Bund is narrower (41bp against 72bp). Do not report that as a threshold effect. The wide Italian spread in the below state is substantially just 2011–2012, and the calm state is only the last nine months. The comparison cannot separate the threshold from the decade.

Yen appreciation against the euro significantly widens BTP–Bund (p<0.001), while sterling appreciation does essentially nothing (p=0.92). That asymmetry is the useful part: it is consistent with a specifically JPY-carry channel into ECB fragmentation pressure rather than a generic risk-off channel, which would move both. It is the first quantitative support in this project for the carry → intervention link.

Two honest qualifications. The relationship is contemporaneous at monthly frequency, so it establishes co-movement, not direction — BTP–Bund widening and yen strength could both be responses to a third thing. And d_fr_bund_bp enters the same equation at +1.83 with z=8.54, meaning France and Italy move nearly one-for-one; the ECB equation's high R² is substantially France explaining Italy.

The France hypothesis is not yet supported — and that is not a refutation

The France regression returns R² = 0.035 with no coefficient significant at conventional levels. The closest is the Germany–Japan spread at p=0.11, and its sign is negative.

This does not refute Tom's instinct. The hypothesis is about funding-market microstructure — repo specialness, collateral quality, bank wholesale funding, auction mechanics — and the test is being run on monthly OECD-frequency benchmark yields, which cannot see any of that. A null here is close to what a correct model of an invisible mechanism would produce. It does mean the public-data version of this question has been asked and answered, and further progress requires the practitioner layer.

Where the model is genuinely blocked

These are the questions where no amount of additional public data helps, framed for Matt Dines and Vince Lanci.

What is the actual trade?
Outright FX, cross-currency basis, swap spread, repo-funded sovereign basis, or a combination? Which tenor carries the risk? This determines every variable specification downstream and is the single highest-value input.
Who holds the vulnerable book?
The model can locate stress in prices but cannot see balance sheets. French bank wholesale funding, LDI-style leverage in the UK, and the identity of the levered holder are all invisible in public series.
Are 180 and 0.85 actually defended?
What would count as evidence — options positioning clustered at the strike, dealer hedging flow, official commentary timed to approaches? Right now these are levels Tom observes the ECB reacting to, and the public data cannot distinguish a defended boundary from a coincidence.
Is CHF really absorbing carry capacity?
The public rate geometry is suggestive — CHF funding is cheaper than JPY by 131bp on the latest common 3-month observation — but the regression finds nothing (p=0.18). Needs CHF forwards, cross-currency basis, and actual SARON funding terms.
France-specific diagnostics
OAT–Bund alone is too coarse. Wanted: French sovereign and bank CDS, OAT repo specialness, auction tails and bid-to-cover, France/Germany collateral differentials, and OAT–Bund volatility rather than level.

Picking this up cold

  1. Rotate the FRED key. It was written in plaintext by the pre-fix run and is present in that output's run_metadata.json and in the session logs. The script no longer does this, but the exposed key is still exposed.
  2. Do not treat the regime table as evidence until the era confound is addressed. The most direct fix is to test the thresholds within period — compare behaviour in windows approaching a crossing against matched non-crossing windows in the same era, rather than pooling twenty years.
  3. Push on the BTP–Bund result, since it is the one live finding. Add leads and lags to separate co-movement from sequence, and condition on identified ECB operations (PEPP, TPI, reinvestment skews) to test whether the relationship concentrates around intervention episodes.
  4. Re-specify France at higher frequency once practitioner data arrives. The monthly public test is exhausted.
  5. Populate the optional market-data template. Every "critical data gap" line in the falsification scorecard resolves to this one file: optional_market_data_v2_template.csv.
Known non-blocking issue

pandas 3.0 emits a Pandas4Warning about default concat sort order at line 475. Harmless now; it becomes an error under pandas 4.
