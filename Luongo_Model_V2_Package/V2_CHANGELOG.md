# V2 changelog

V2 incorporates Tom Luongo's feedback after the first empirical pass.

- France/OAT-Bund becomes the primary public continental weak-link proxy.
- Italy/BTP-Bund is reclassified as an ECB fragmentation/intervention-state signal rather than the victim variable.
- UK/London remains a separate stress channel.
- US/UK/JP long-end spread relationships are retained as diagnostics but explicitly labeled algebraically linked; the economic test moves to short funding + FX + basis/repo/hedging.
- CHF/SNB is added as a candidate substitute source of carry capacity as Japanese funding normalizes.
- EUR/JPY 180 and EUR/GBP 0.85 are treated as pre-specified threshold hypotheses with crossing/event/placebo tests.
- V1 event-study windowing is corrected to use actual observed dates; price/index moves are log percentage changes while rates/spreads are level changes.
- Optional premium-data schema now includes cross-currency basis, repo, CDS, funding, hedge-ratio and margin inputs needed for executable carry and vulnerability identification.
